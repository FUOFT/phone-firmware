# phone-firmware
Надо скачать Fastphone для управление в приложении консоль указывайте адб или фастбут тогда будет все работать
Потом нужно скачать драйвера на устройство что бы кабель работал 

# Тутор на драйвера
1. скачивайте Fastusb открывайте Диспетчер устройств, выбираем наше устройство
2. нажимаем ПКМ и обновить драйвер, потом найти драйверы на этом компьютере
3. выбрать драйвер из списка 
4. устанавливайте драйвера выберайте 3 разных версии какие нужны 

# Тутор на приложение 
1. скачивайте Fastphone
2. скачивайте Приложение
3. внутри заходите в консоль выбирайте ADB и укажите путь где находится файл ADB.EXE
Примечание: Конфиг потом сам сохранится и заново не надо делать
